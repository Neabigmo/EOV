## 0｜这份文件要防的是什么

M5 是 **discovery**：`f1_landscape_rho` → `ρ_rank` 的关系是在 Phillips2023 + TEM-1 上"发现"的。
M6 是**唯一一次确认**。它要防的是最危险的质疑：

> **"你看完 discovery 结果之后，又挑了一个最容易复现的数据集。"**

因此本文件在两处做硬约束：

1. **数据选择不能是结果依赖的**：AncSR1 在 `PROVENANCE_LEDGER.csv` 里**早已登记**
   （`conditional` 角色，CC0-1.0），是 **M5 结果出现之前就存在的候选**。
   → 用它不是"挑一个容易的"，而是"用清单上的下一个"。
2. **设计不能是结果依赖的**：本节与 §3–§7 的全部内容在**看数据之前**写死；
   之后只允许"执行"，不允许"调整"。

只有在一种情况下才转去找替代数据 —— **§6 的结构资格审计（不看 phenotype 值）判定它不适格**。
**"确认结果不好"不在可转数据的理由之列。**

## 1｜假设（单一、有方向）

> **H₁**：在两个 task 之间，**单变体景观相关 `f1_landscape_rho` 越高，起点价值的排序迁移 `ρ_rank` 越好。**

- **方向预先指定：正。** 不做双侧、不做反向解释。
- 这是**唯一**被检验的假设。M5 里其它候选（`f6_robustness_consistency`、`f3_sign_epistasis_agree`）
  **在本轮一律不检验、不报告为结论**（`f6` 与 `f1` 高度相关，`f3` 方向反直觉且 M5 未解释）。

## 2｜主特征与主结局（继承 M5，不得改）

| | 定义 | 出处 |
|---|---|---|
| **主特征（唯一）** | `f1_landscape_rho` = 两个 task 在**共同 informative 基因型**上、`value_group` 的 Spearman 相关 | M5 `eov/m5_transfer_map.py::pair_features` |
| **主结局（唯一）** | **pair-level `ρ_rank`** = 对 9 个 `(policy × budget)` 格先各自算 Spearman(V_A, V_B)，再取**均值** | M5 `eov/m5_explain.py` |
| `V_τ` 定义 | `V_τ(x) = u_τ(R_{B,π}(x,τ))`，`R` = 被测集合（含起点）的最大值 | `PHASE1_DECISION.md` §2.3 |
| `u_τ` 尺度 | `OP-12`，**无 clip**（`AMENDMENT-013 §1` / `AMENDMENT-014 §3`） | 冻结 |
| 策略 | `random` / `greedy_ssm` / `mlde_ridge` | M5 |
| 预算 | `{24, 96, 384}`，**受 `OP-21`（`B ≤ |space|/4`）约束** | M5 + `AMENDMENT-002 B-2` |
| 搜索实现 | `eov/search_sim.py`（唯一实现） | 冻结 |

**`OP-21` 的预指定处理**：若某档 `B > |space|/4`，**该档整体剔除**（三个策略在该档都不算），
`ρ_rank` 在**剩余档位**上取均值；若剩余不足 **2 个预算档**，则该数据集在 §6 判为**不适格**。
此规则**在看到空间大小之前写定**，避免"挑一个能通过的档位"。

## 3｜成功阈值（预先指定）

- **主判据**：`Spearman(f1, ρ_rank)` 在 AncSR1 的全部 task pair 上 **≥ 0.45**，
  **且** 95% bootstrap CI（按 pair 重采样，2000 次）**排除 0**。
- 阈值 **0.45** 的来源（**不是凑的圆整数**）：M5 在**单一数据集内部**的两个估计是
  **TEM-1 全部 18 对 = +0.451** 与 **TEM-1 同药 16 对 = +0.744**。
  取**其中较弱的一个**（+0.451）作为确认门槛 → 确认必须至少复现 M5 的**下界**。
- **辅判据（必须同报，不参与判定）**：绝对迁移水平 `ρ_rank` 的 pair-level 中位数。
  M5 的两个锚点是 全 21 对 **0.0599**、同药 16 对 **0.0451**。
  → 用于回答"**低绝对迁移**是否复现"，但**不改变 GO/NO-GO**。

## 6｜结构资格审计（**不看 phenotype 值**，一次性通过/不通过）

在读取任何 `value_group`、计算任何相关**之前**，只做下列结构判定：

| # | 判据 | 通过条件 |
|---|---|---|
| E1 | **task 数** | ≥ 3（否则 pair 数 < 3，无法做相关） |
| E2 | **可定义的 task pair 数** | ≥ **10**（阈值预先写定；见下注） |
| E3 | **空间可定义** | 能构造完整乘积空间，或能明确界定"可测基因型集合" |
| E4 | **邻接可定义** | **AA Hamming-1** 可定义（`AMENDMENT-007` 已记录 AncSR1 的**单核苷酸邻接陷阱**）→ 若只有核苷酸邻接，需能映射到 AA 邻接；**不能**则不通过 |
| E5 | **graph eligibility** | 各 task 的 `informative_frac` 足够，且满足 `PHASE1_PROTOCOL` 的 `graph_eligible` 规则 |
| E6 | **预算可定义** | `OP-21` 之下仍 ≥ 2 个预算档 |

> **E2 阈值 10 的来源**：M5 的证据里最弱的一组是 TEM-1 同药 **16 对**；
> 要求 ≥ 10 对是"确认集不必大于发现集、但必须足以让 Spearman 有意义"的最低线。
> **此阈值在读到任何 AncSR1 数值之前写定。**

**审计只允许输出**：结构表（task 数、genotype 数、pair 数、缺失率、空间大小、邻接类型、E1–E6 逐条判定）。
**不得输出**任何 phenotype 分布、任何相关、任何既视感判断。

## 8｜**范围限制（必须随结论一起声明）**

`f1_landscape_rho` **需要两个 task 的景观值才能计算** —— 它**不是**一个"今天就能算"的前瞻性特征。

因此本确认若成功，能支持的是：

> **"任务可迁移性可由任务相似性预测"** —— 一个**诊断/设计层面**的结论
> （例：决定要不要做 multi-task campaign、预期多少迁移）。

它**不能**支持：

> ~~"今天就能预测明天"~~ —— 那需要一个**只用 τ₀ 数据**的相似性代理，
> 而那是一个**不同的特征**，不在 M6 范围内。

**此限制必须在 M6 报告的摘要里逐字出现。**
