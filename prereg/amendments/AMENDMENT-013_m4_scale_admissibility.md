## 1｜修正 C1：OP-12 的 `clip` 是未授权添加（**删除**）

**冻结原文**（`PHASE1_PROTOCOL.md` L93 / L259）：

```
u_τ(z) = (z − q_{0.05}) / (q_{0.95} − q_{0.05})
```

**没有任何 `clip`。** 对比 §3.1 的锚点尺度（L77）**显式写了 `clip(..., 0, 1)`** —— 冻结文本的"有 clip / 无 clip"是分开写的，不是笔误。

**我的实现擅自加了 `np.clip(..., 0, 1)`**。后果（Exp 1 首跑实测，MA90，1000 parents）：

| 策略 | B | mean V | sd V | **frac(V == 1.0)** |
|---|---|---|---|---|
| random | 24 | 0.9907 | 0.0221 | **0.725** |
| random | 96 | — | — | 使相关系数成为 `nan` |
| random | 384 | — | — | 使相关系数成为 `nan` |

即：**B=24 时 72.5% 的 parent 已经饱和到 1.0**，B≥96 时全部饱和 → `Corr(V_B1, V_B2)` 的分母为 0 → `nan`。

**裁决：删除 `clip`，恢复冻结公式。**（`scale2max` 敏感性尺度按 §3.3 照旧报告。）
**说明**：这不是口径变更——OP-12 的不变式是"跨 landscape 可比"，仿射尺度已经满足；clip 是我引入的、把分辨率摧毁的额外操作。

## 2｜修正 C2：新增**预注册准入规则**——锚点可分辨性

### 2.1 问题（**本次最重要的发现**）

§3.1 把 TEM-1 的主尺度定义为

```
u_anchor_τ(z) = clip( (z − F_dead) / (F_WT − F_dead), 0, 1 )
```

该式隐含前提：**`F_WT` 与 `F_dead` 必须彼此可分**。若两者之差小到与测量噪声同阶，分母就是噪声 → `u` 被噪声放大到任意尺度，而 `clip` 又把大多数点压到两端 → **"任务间差异"由纯噪声制造**。

### 2.2 准入量（本修正冻结）

```
anchor_resolvability(τ) = |F_WT − F_dead| / median_genotype(value_sd_τ)
```

- 只用该条件 **informative** 基因型的 `value_group`（median）与 `value_sd`（median）。
- **准入阈值：`anchor_resolvability ≥ 2.0`** → 可用 §3.1 锚点尺度；否则该条件**必须**退回 §3.3（OP-12，无 clip）。
- 敏感性（更严）：把噪声单位换成两个参照点各自 median 的标准误，即要求 `sep ≥ 2·√(SEM_WT²+SEM_dead²) ≈ 1.63·value_sd`。**阈值 2.0 相对它是保守的**（更严）。

### 2.4 灾难的量级（为什么必须拦）

若在 AZT@36 上照用锚点尺度：

| 量 | 值 |
|---|---|
| 落入 `u > 1`（被 clip）的基因型比例 | **66.5%** |
| 落入 `u < 0`（被 clip）的比例 | **5.9%** |
| `u(q95)` | **4.73** |
| `u(max)` | **15.48** |
| 该尺度的一个"单位" `F_WT−F_dead` | **0.202** |
| 该条件的测量噪声 SD | **0.242** |

→ **一个单位比一个噪声单位还小**。这正是"不报错、只是数字错"的失效模式的最坏形态：它会**自动**生产出巨大的跨任务差异、巨大的 `AdaptationPremium`、以及一个漂亮而完全虚假的"readiness ≠ EOV"。

## 3｜修正 C3：`mlde_ridge` 的两处实现缺陷

| # | 缺陷 | 后果 | 修正 |
|---|---|---|---|
| C3a | 名字是 ridge，实现是 `np.linalg.lstsq`（零正则 OLS） | 设计矩阵 one-hot + 截距**恒为秩亏**（每个位点的哑变量之和恒等于截距），B=24 时 n=12 < p=17 | 改为**真 ridge**，λ = **1.0**（对 y 标准化后），**不做任何调参** |
| C3b | 预测值并列时 `argpartition` 按**索引序**取 top-b | 所有 parent 收敛到同一批低索引基因型 → V 为常数 → 相关系数 `nan`（Exp 1 首跑 9/9 个 MLDE 相关均为 `nan` 即此因） | 并列时**随机**打破 |

两处均为**未调参**的固定选择，按 **OP-25（非盲阈值披露义务）**在此披露。λ=1.0 在 y 标准化后是无量纲的，且**未与任何 V/regret 结果对照过**。

## 4｜预承诺：主未来条件由 `AZT@36.0` 改为 `AZT@0.44`，`AZT@36.0` 保留为强制复现

**决定时点：尚未计算任何 `V` / regret / NR。**

| 理由 | 证据 |
|---|---|
| (i) **锚点不可分辨** | AZT@36 的 `anchor_resolvability = 0.832 < 1`；AZT@0.44 = 6.196 |
| (ii) **G-FTI 也最低** | 已冻结的 C9 门控：AZT@36 ratio = 2.068（SEM）/ 1.194（SD）；AZT@0.44 = 4.343 / 2.508 —— AZT@36 是**仅以 SEM 口径勉强通过**的那一个 |
| (iii) **换向不需要新的主观判断** | 两条已冻结的规则（§3.1/§3.3 尺度选择、C9 门控）**同向**指向 AZT@0.44；原选 AZT@36 的唯一依据是"临床断点 32 μg/mL 附近"，那是**临床相关性**论证，不是测量效度论证 |

**同时预承诺**：
1. **AZT@36.0 的完整结果必须一并报告**，作为强制复现；两条件结论不一致时，**不得**只报其一。
2. 主报告**必须**同时给出 `scale2max` 敏感性尺度下的同一结论。
3. **"SEM 还是 SD 作为测量不确定度"的口径分叉就此消解**：`anchor_resolvability` 用的是逐基因型重复 SD 本身，两种口径下 AZT@36 都不通过。
4. 由于 Exp 2/3 的主指标是**未来任务内部的** regret 与 **秩**相关，§3.1/§3.3 的尺度选择对它们**不改变结论**（秩统计量对单调变换不变）；尺度选择只影响 (a) H1 的 heterogeneity/effect-size 报告，与 (b) 任何跨任务**绝对**比较。→ **H1 的效应/噪声比一律用原始量纲计算，不用归一化后单位。**
