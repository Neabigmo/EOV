## 1｜错误 E1：判据 2 的检验**恒无功效**

### 1.1 原实现

`PHASE1_DECISION.md` §Matched-pair confirmation 判据 2 逐字为：

> confirmation split 中至少有 **20 对**……**未来值差异的方向性成功率显著高于 0.5**（二项检验 p < 0.05）

第一版把匹配对记为 `(i, j)`（`i < j` 由 `itertools.combinations` 的**索引序**给出），然后检验

```
P( V_i − V_j > 0 ) > 0.5
```

### 1.2 为什么这没有功效

`i`、`j` 是按**数组索引**排序的，而索引与 `V` **无关**。因此对每一对都有

```
P( V_i − V_j > 0 ) = P( V_i − V_j < 0 ) = 0.5      （在"匹配不改变任何东西"的零假设下严格成立）
```

→ 该二项检验的**真实功效为 0**（只在 α 水平上拒绝）。第一版跑出的 p = 0.21–1.00 并非"没有发现效应"，
而是**这个检验本来就不会发现任何效应**；个别单元出现的 p≈0.008 也不是信号，而是与名义 α 一致的噪声。

**性质**：这是检验设计错误，不是数值 bug —— 它**不报错**，只是永远给不出有意义的数字。
与 AMENDMENT-013 §3b（并列按索引序打破导致常数结果）属**同一类**失效：**索引序偷偷变成了分析的一部分**。

### 1.3 修正后的实现（本条冻结）

在**每一对内部**用一条 Day-0 预测器判断"谁更好"，再与观测到的未来差异比方向：

```
signed_k = sign( P_i − P_j ) · ( V_i − V_j )
方向成功率 = #{ signed_k > 0 } / #{ signed_k ≠ 0 }        二项检验 vs 0.5
```

- **预指定预测器 = `Readiness`（`known_family_mean`）**。理由：被判据检验的假设逐字就是
  "`Readiness ≠ EOV`"，所以 `Readiness` 是**假设本身指定的**预测器，不是从数据里挑的。
- 其余预测器（`current_fitness` / `local_robustness` / `proxy_eov_today`）只作**探索性**报告，
  并须按 **4 重比较**降权（`exploratory_best_*` 列即"4 个里取最小 p"，**有选择偏倚**，不得作为判据）。
- 判据 2 的判定**只用** `Readiness_p`。

## 2｜错误 E2：`sd_ratio` 的 bootstrap CI 算在**分子**上

第一版：

```
ratio = sd(dv | 匹配) / sd(dv | 随机配对)      # 点估计是"比值"
CI    = percentile( bootstrap of sd(dv | 匹配) )   # 但 CI 是"分子"
```

点估计与 CI **不同量纲**，于是打印出 `sd_ratio=0.589 [0.098, 0.151]` 这类自相矛盾的读数。

**修正**：CI 重采样**比值本身**，分母用固定的置换零分布 `null_sd`（200 次随机配对取均值）。

## 3｜新增的直测统计量（判据 1 的加强，不替代任何冻结判据）

匹配对设计要回答的中心命题是"**同一个现在、不同的未来**"。它有一个**直接**的、不需要预测器的检验：

```
ratio = sd(V_i − V_j | 在 Readiness 与全部 proxy 上匹配) / sd(V_i − V_j | 随机配对)
今天信息已解释的未来方差份额 = 1 − ratio²
```

| `ratio` | 含义 |
|---|---|
| → 1 | 今天的信息**不约束**未来 → **"同一个现在、不同的未来"成立** |
| → 0 | 今天的信息**已决定**未来 → EOV 无独立内容 |

**为什么比值 1 是零假设**：随机配对时 `Var(V_i − V_j) = 2σ²_V`；
若匹配所依据的信息对 `V` 无约束，匹配对的 `V` 仍是同分布独立抽样，方差同样为 `2σ²_V`。

**披露（OP-25）**：该统计量是**本条新增**的，不是 `PHASE1_DECISION.md` 里已有的判据。
它**只作加强证据**，**不替换**判据 1/2/3；报告时必须与冻结判据分开标注。
