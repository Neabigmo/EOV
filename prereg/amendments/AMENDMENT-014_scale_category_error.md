## 1｜论点（类错误，不是噪声问题）

`PHASE1_PROTOCOL.md` §3.1 定义

```
u_anchor_τ(z) = clip( (z − F_dead) / (F_WT − F_dead), 0, 1 )
```

它的语义是：**"这个变体相对 WT 强多少倍"**（dead = 0，WT = 1）。因此它被设计用来**比较单个变体**。

而 `R_{B,π}(x,τ)` 是**定向进化后的终点**。定向进化的定义就是**系统性地超过 WT**。
→ `clip(·, 0, 1)` 把"超过 WT"的**整段区间**映射到同一个点 1 → **分辨率归零**。
→ 这不是"尺度选得不好"，而是**把单变体标尺用在终点量上**的类错误。

## 3｜裁决：TEM-1 的**全部**估值量统一用 §3.3（OP-12，无 clip）

### 3.1 为什么必须"统一"，不能"分层用"

`AdaptationPremium = EOV − Readiness`，其中

- `Readiness(x) = E_τ[u_τ(R_0(x,τ))]`，`R_0 = F_τ(x)` 是**单个变体**的值 → §3.1 对本项**是**良定义的；
- `EOV_{B,π}(x) = E_τ[u_τ(R_{B,π}(x,τ))]`，`R_{B,π}` 是**终点** → §3.1 对本项**饱和**。

若"哪里能用在哪儿用"，则 `AdaptationPremium` 变成**两个不同尺度的差**——这正是 `PHASE1_DECISION.md` §2.4 不变量 1 要防的、也是 `LANDSCAPE_HUNT_v0.md` L799 预言"当场就会爆炸"的 B4 类 bug 的**尺度版本**。

→ **`R_0`、`R_{B,π}`、`V`、`EOV`、`Readiness`、`AdaptationPremium`、`Regret`、`NR` 必须共用同一尺度。**
→ 该尺度由 `R_{B,π}` 决定 → **TEM-1 全栈用 §3.3（OP-12，无 clip）**。

### 3.2 这**不是**移动球门，理由有三条（全部可核验）

1. **§3.1 在此处不可用是"被证明的"，不是"被选择的"**：A1/A2 两条判据都是在看任何结果**之前**冻结的；TEM-1 是**全票不通过**（A2 零通过），不存在"挑一个好看的"自由。
2. **退回的尺度是冻结文本里现成的**：§3.3 原文即为"无 dead 锚点 landscape"的主尺度，§3.2（empirical quantile）为其敏感性。本轮只是把适用条件写成显式判据。
3. **尺度选择在数学上无法制造我们的结论**：OP-12 是 `value` 的**仿射**变换（`(z−q05)/(q95−q05)`，无 clip）。
   - Spearman / 秩 / 任一 parent 的 argmax → **完全不变**；
   - `NR` 的分子与分母**同尺度** → `NR` **完全不变**；
   - 只有**跨任务绝对量**（如 `EOV` 的绝对水平、`AdaptationPremium` 的绝对大小）受尺度影响 → 对这些一律**并报** §3.2 与 `scale2max` 敏感性。

### 3.3 强制报告义务

1. 所有涉及 `V` / `EOV` / `AdaptationPremium` **绝对水平**的结论，必须同时给出 **`scale2max`** 与 **§3.2 empirical-quantile** 两种尺度下的同一结论；三者不一致时**必须**如实报告冲突，不得只报其一。
2. H1 的效应/噪声比**一律用原始量纲**（`IQR(R)` vs `2 × median(value_sd)`）。注：由于 OP-12 是仿射的，`IQR(u)/noise(u) ≡ IQR(R)/noise(R)`，故二者**恒等**，此条只是避免把尺度写进分母。
