# EOV — Evolutionary Option Value

**Starting-point value is budget-stable but strongly task-conditional, and how
much of it transfers is governed by landscape similarity.**

This repository contains the code, the pre-registration, the provenance ledger
and the result tables for a Phase-I study of what makes a protein variant a good
*starting point* for future evolution — as opposed to a good variant today.

> **No third-party dataset is redistributed here.** See
> [`docs/DATA_ACCESS.md`](docs/DATA_ACCESS.md). Everything in `results/` is a
> small derived table produced by the code in this repository.

---

## 1. Main findings

1. **Within-task starting-point value is budget-stable.** Across budget tiers the
   parent ranking correlates `ρ = 0.833 / 0.929 / 0.994` (min / median / max).
2. **Cross-task transfer is usually weak.** Pair-level `ρ_rank` has median
   `0.0599` in discovery and **`0.0021`** in independent confirmation.
3. **Landscape similarity predicts how much transfer remains.**
   `Spearman(f1_landscape_rho, ρ_rank)` = `+0.7441` (discovery, same-drug
   subgroup) and **`+0.7536`** in independent confirmation.
4. **That confirmation is independent**: a different organism, a different task
   axis (six H2N2/H3N2 strain backgrounds), a different genotype alphabet — and
   the dataset was chosen by a **phenotype-blind structural rule written down in
   advance**. Frozen threshold was `≥ 0.45`; result `+0.7536`,
   95% bootstrap CI `[+0.2318, +0.9445]`.
5. **About 16 shared measurements suffice** to estimate whether an existing
   starting-point ranking is worth carrying into a new task (`m* = 16`,
   `ρ̂ = +0.6659`). The practical minimum is set by the *single-draw* 5th
   percentile: `0.079` at `m = 4`, `0.401` at `m = 16`.
6. **A zero-measurement gate from task metadata failed.** Using only drug
   ECFP4-fingerprint × dose and strain isolation year, `ρ_zero = +0.3527` with a
   task-cluster bootstrap CI `[−0.1520, +0.6747]`; decisively, the
   lowest-similarity tertile has median transfer `+0.0407` — **identical to the
   whole sample**. Verdict **NO-GO**.

The last point is not a footnote. It says the predictor in (3)–(5) is *not*
something one could have guessed from task labels: it genuinely requires
measuring a little of the future.

## 2. Concept

Starting-point value is **relational, not intrinsic**:

```
EOV_{B,π}(x | τ)                     value of parent x, task τ, budget B, policy π
V_{B,π}(x, τ) = u_τ( R_{B,π}(x, τ) ) best value reached from x under budget B
u_τ(z) = (z − q05_τ) / (q95_τ − q05_τ)      OP-12, empirical quantiles, no clip
```

The transfer operator, and what the study actually models:

```
T(τ_s → τ_t) = Corr_x[ V(x, τ_s), V(x, τ_t) ]        ≈ g( S(τ_s, τ_t) )
```

`S` is landscape similarity. In M6/M7 it is `f1_landscape_rho`: the Spearman
correlation between the two tasks' values over shared informative genotypes.

**Retired framings** (do not reintroduce): the scalar `EOV(x)`, and
`EOV = R_B − R_0`, which was abolished outright. `AdaptationPremium` is reported
but is **never** an optimisation target.

## 4. Installation

```bash
git clone <REPOSITORY URL>
cd EOV
python -m venv .venv && . .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt                 # numpy, pandas, pytest
```

The full pipeline additionally needs `pip install -e ".[full]"` (scipy,
openpyxl, rdkit, rdata, pyarrow). None of that is needed for the tests or for
the zero-download stage.

## 5. Data acquisition

No dataset is shipped. `data_registry/PROVENANCE_LEDGER.csv` records all 25
datasets with their official source, license and redistribution basis;
`configs/dataset_manifest.csv` is derived from it.

```bash
python scripts/fetch_public_data.py --list        # what exists and how to get it
python scripts/fetch_public_data.py --dataset wu2020
```

Read [`docs/DATA_ACCESS.md`](docs/DATA_ACCESS.md) first — in particular the rule
that the governing license is that of the **artifact actually ingested**, not the
paper's license and not a mirror's.

## 6. Reproduce key results

```bash
python scripts/reproduce_phase1.py --check          # what is present / missing
python scripts/reproduce_phase1.py --stage m7b      # zero downloads, seconds
python scripts/reproduce_phase1.py --stage m6       # needs the Wu2020 xlsx
python scripts/reproduce_phase1.py --stage all
```

Every stage names the exact file it needs and the command that fetches it.

| stage | downloads needed | rough runtime |
|---|---|---|
| `m7b` | **none** | seconds |
| `m6` | Wu2020 Source Data (174 KB, CC-BY-4.0) | ~11 s |
| `m5` | TEM-1 + Phillips2023 | minutes |
| `m4` | TEM-1 + Phillips2023 | long (search simulation) |
| `m7` | all of the above | minutes |

Each headline number also has an independent verifier, e.g.
`python eov/m7b_verify.py` (65 checks), `python eov/m6_verify_result.py`
(85 checks). These re-derive the statistic by a separate code path and then check
the report text against the computed values.

## 7. Tests

```bash
pytest tests
```

* **No third-party data present** → `66 passed, 20 skipped`, exit 0. The skips
  are declared in `tests/conftest.py`, so the same command runs the full suite
  once data is present.
* **Full data present** → `86 passed`.

The frozen v1.1/v1.2 test assets are hash-asserted by tripwires in the suite;
they are shipped **byte-identical** and must not be edited.

## 8. Reproducibility and pre-registration

Every threshold, `m` grid, descriptor formula and seed was frozen **before** the
analysis it governs, in `prereg/`. `data_registry/FREEZE_LEDGER.md` is an
append-only record of every batch of files and their SHA-256.

Negative results and self-caught protocol flaws are kept on purpose — see
`AMENDMENT-019`, `AMENDMENT-020` §3 and `AMENDMENT-021` §3, and the summary in
[`docs/PROJECT_HISTORY.md`](docs/PROJECT_HISTORY.md).

Details: [`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md).
