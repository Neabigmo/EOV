# M7-B 报告 —— Zero-measurement transferability gate：**NO-GO**

| 字段 | 值 |
|---|---|
| 标签 | **EXPLORATORY / design characterisation**（不是确认检验） |
| 依据 | `prereg/AMENDMENT-021_m7b_zero_measurement_gate.md`（计算前冻结） |
| 判定 | ❌ **NO-GO**（按用户 §7 的判据逐条实现后的结果） |
| 后续 | 按用户明示：**停止**。不加 descriptor、不上 Transformer、不上 LLM embedding 去救 |

---

## 0｜摘要

> **只用"任务是什么"（药身份 + 剂量；毒株年份）的零测量描述符，
> 可以检出一个方向正确的弱关联（`ρ_zero = +0.3527`，系统内置换 `p = 0.016`），
> 但达不到预注册的门槛，并且——这是决定性的——它无法完成本实验唯一的实用目的：
> 最低相似度的一组并没有筛出"迁移不可用"的 task pair。**
>
> `median(T | S_0 最低三分位) = **+0.0407**`，与**全样本中位 +0.0407 完全相同**
> （`median(T | 其余) = +0.0434`）。**`S_0 low ⇒ T ≈ 0` 不成立。**
>
> → **NO-GO。** 本轮的结论不是"零测量 gate 可用但弱"，而是
> **"零测量 gate 在其预定用途上不成立"**。

## 2｜两种 bootstrap 的对照（为什么用 cluster 版）

| 方法 | 95% CI | 是否排除 0 |
|---|---|---|
| **task-cluster**（主，按 14 个 task 重采样） | **[−0.1520, +0.6747]** | ❌ **跨零** |
| 朴素 pair（对照） | [+0.0457, +0.6143] | ✅ |

每次 cluster 重采样平均只抽到 **9.04** 个去重 task（14 个里），所以 pair 集明显变小、CI 明显变宽。
**朴素 pair bootstrap 会给出"显著"的假象** —— 这正是你 §6 预判的 pair 依赖问题，
本数据上它是**实质性的**，不是形式问题。

## 3｜判定（**`AMENDMENT-021` §5 三档，逐条完整实现**）

| 档位 | 条件 | 实测 | 结果 |
|---|---|---|---|
| **Primary GO** | `ρ_zero ≥ 0.45` **且** cluster CI 下界 > 0 | `0.3527 < 0.45`；下界 `−0.1520` | ❌ 不满足 |
| **Conditional GO** | `0.25 ≤ ρ_zero < 0.45` **且**方向正确 **且** `p < 0.05` **且** bottom tertile 能筛出低-transfer pair | `0.3527` ✅；方向 ✅；`p=0.016` ✅；**bottom tertile ✗** | ❌ 不满足 |
| **NO-GO** | `ρ_zero < 0.25` **或** CI 大幅跨零 | CI `[−0.152, +0.675]` 跨零 | ✅ **命中** |

**→ NO-GO。**

### 3.1 那个决定性的失败：三分位

| 三分位 | `S_0` 范围 | `T` 中位 | 均值 | IQR | 最大 |
|---|---|---|---|---|---|
| **low** | [0.0000, 0.0450] | **+0.0407** | +0.0298 | 0.0931 | +0.1286 |
| mid | [0.0608, 0.2999] | +0.0073 | +0.0189 | 0.0877 | +0.2008 |
| high | [0.3001, 0.5516] | +0.0532 | +0.0646 | 0.0625 | +0.1522 |
| **全样本** | — | **+0.0407** | +0.0378 | — | +0.2119 |

**低相似度组的中位迁移量与全样本中位逐位相同（+0.0407）**，
且排序**非单调**（mid 最低）。`S_0` 完全**没有**把"迁移不可用"的 pair 聚到一端。

> 用户判据的**无阈值操作化**（忠实原话，不引入新常数）：
> `low_screen ⟺ median(T|low) ≤ 0 且 median(T|low) < median(T|high)`。
> 实测 `+0.0407 > 0` 且不小于 `+0.0532` → **不成立**。

## 5｜`Phillips2023` 本轮 **not evaluable**（`AMENDMENT-021` §2.1）

该数据集 task 轴是"哪一个 H1 抗原"（`MA90` / `SI06` / `G189E`）。
要定零测量相似度就需要**抗原序列**，而它**不在本工作区**。
按"不同系统不要硬拼 descriptor"的原则，**登记为不可评估**，而不是编一个序数相似度。

**后果（必须与结论同现）**：M7-B 只覆盖 **2 个系统**，
所以**不能**说"跨三个独立系统"。

## 6｜这个 NO-GO 本身是有信息量的（**但不是补救尝试**）

M6/M7 与 M7-B 合起来给出一个**干净的分工**：

| 量 | 预测 `T = ρ_rank`？ | 需要什么 |
|---|---|---|
| `f1_landscape_rho`（**景观**相似度，全部基因型） | ✅ **+0.7536**（M6 确认） | 测**整个** future 景观 |
| `f̂₁`（**景观**相似度的 16 点估计） | ✅ **+0.6659**（M7） | 测 **≈16** 个共享基因型 |
| `S_0`（**任务元数据**相似度） | ❌ **+0.3527，且无法筛除**（M7-B） | **0** 次测量 |

> **结论**：**任务元数据的相似度不能替代景观相似度的测量。**
> 换句话说，M6/M7 的预测能力**不是**"从任务标签就能猜到的东西"——
> 它确实要求**去测一点未来**。这反过来**加固**了 M6 与 M7 的结论，
> 而不是削弱它们。

**两级 gate 的处置**：
- ❌ **Stage 1（零成本 metadata gate）不成立** —— 本轮已判 NO-GO；
- ✅ **Stage 2（≈16 个共享基因型的校准）保留** —— M7 已独立确认。

→ 论文里**只保留一级**，即"**测约 16 个共享变体来决定是否迁移**"。
**不再宣传零测量 gate。**

## 7｜⚠️ 本轮自己抓到的一处实现错误（值得记）

首版判定逻辑**漏实现了 Conditional GO 的第三个条件**
（"bottom tertile 能稳定筛出低-transfer pair"），于是把结果打印成 **"Conditional GO"**。
三分位数据随后显示该条件**明确失败**，正确档位是 **NO-GO**。

**处置**：不改任何阈值、不改任何公式，只把 §5 的**三档判据逐条完整实现**并重跑；
在代码里留下修正记录注释；本报告采用修正后的判定。

> **第 31 条工程纪律（新增，永久）**：**判定逻辑本身也要有"逐条对照预注册"的核验。**
> 前 30 条纪律都在管数据与统计，这一条管**判据的实现**：
> 多档判定（GO / Conditional GO / NO-GO）必须**逐条列出**每个条件的实测值，
> 而不是写成一个 `if/elif` 链就交差 —— 链条会静默漏掉条件，
> 而漏掉的那一条恰好可能是"决定档位"的那一条。
> 触发场景：M7-B 首版把 Conditional GO 的 tercile 条件整个漏掉。

## 8｜范围限制（`AMENDMENT-021` §8）

1. 仅 **2 个系统 / 14 个 task / 33 个 pair** —— 样本小，**不声称普适**。
2. `Phillips2023` **not evaluable**；"三个独立系统"的说法**不成立**。
3. `S_0` 是**粗粒度代理**，不是"任务相似度真值"。
4. **不改变绝对迁移结论**：M6 pair 级中位 `0.0021`、M5 `0.0599`、M7 high 档 `+0.0906` **一律不变**。
5. 本轮的 NO-GO **不**授权任何补救式扩展（用户明示）。
