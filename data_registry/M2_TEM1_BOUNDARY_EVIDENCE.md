## 2｜决定性证据：`0.1760912591 ≡ log10(1.5)`

| 文件 | 最小值 | 原始字节精度 | 位于最小值的单元数 |
|---|---|---|---|
| `data/raw/Ampicillin_auc_per_genotype.csv` | **0.1760912591** | 与 `log10(1.5)` 逐位相同 | **47,839 / 1,098,438 = 4.36%** |
| `data/raw/Aztreonam_auc_per_genotype.csv` | **0.1760912591** | 同上 | **54,857 / 1,454,248 = 3.77%** |
| `data/processed/amp_auc_wide_df.parquet`（AMP 781） | **0.176091** | — | 3,814 / 165,836 = **2.30%** |
| `data/processed/azt_auc_wide_df.parquet`（AZT 36） | **0.176091** | — | 24 / 165,820 = **0.01%** |

- `log10(1.5) = 0.17609125905568124…` → **与实测最小值的 10 位小数完全一致**。
- 该值在**两个药物、两种格式（raw/processed）共 4 个文件中完全相同**。
- 无 0 值、无负值（因此不存在 `log10(0) = -∞` 的情形）。

**推断**：管线先计算 AUC（线性量），其**下界被固定为 1.5**，再取 `log10` → 得到这条硬下限。
→ 这是**跨药物共享的管线下限**，不是"AMP 的检测限"或"AZT 的检测限"。

**未验证的部分（必须标注）**：`1.5` 这个常数**为何**出现（归一化方式？积分窗口？零点基线？），作者未说明，**我无法从数据反推确定**。因此 `boundary_status = inferred` 而非 `explicit`。

## 3｜重要修正：宽表**不是** log 变换后的值，而就是管线输出的那个量

早前我把宽表的值称为"AUC-fitness"并假定是 `log10(AUC)`。实测显示：

- 宽表 AMP 781 的 max = **5.0524** ≈ 原始文件 max = **5.0798**；min 与原始文件**完全相同**（0.176091）。
- → **宽表与 raw 表承载的是同一个量**（管线输出的、已含 log 变换的量）。

**对 schema 的影响**：`value` 的语义应记为 **"pipeline-normalized AUC-fitness（含 log 变换，机制未文档化）"**，**不得**再写成"raw AUC"，也不得在未声明的情况下再次取 log。

## 4｜CL-7 的组级删失签名：**罕见但确实存在**

CL-7 要求「三重复**完全相同** ∧ `SEM == 0` ∧ 命中已验证边界」。实测（AMP 781）：

| 指标 | AMP 781 | AZT 36 |
|---|---|---|
| 三重复完全相同的组 | **53 / 55,294** | **0 / 55,294** |
| 位于下限的单元 | 3,814（2.30%） | 24（0.01%） |

**关键解释**：位于下限的**单元**很多（3,814），但三重复**全部**落在下限的**组**只有 53 个 —— 说明**下限是逐观测（per-replicate）生效的**，而 CL-7 是**组级**判据。二者不可混为一谈。

→ **不能用"2.30% 的单元在下限"去声称"2.30% 的测量被删失"。**

## 5｜⚠️ 需要你裁决：`inferred` 边界是否足以产出 `censored`？

按 AMENDMENT-009 §3.3 的规则链：

> **`boundary_status = unresolved` ⇒ 不得产出任何 `censored` 分类**

现在的情形是 `inferred`（不是 `unresolved`，也不是 `explicit`）。你的原话要求 censored 必须命中**"已验证 boundary"**，而 `inferred ≠ verified`。

**我的建议（请你裁决）**：

- **`boundary_status = inferred`、`boundary_source = transformation`** 照实登记；
- **但在 M2 不产出任何 `censored` 分类**，改为新增一个**诊断标记** `at_inferred_floor = True`（保留 `measurement_state = measured_exact`）；
- 是否把该标记升级为 `censored`，由你出一条**显式裁决**（可预注册为："凡 value == log10(1.5) 的观测，在敏感性分析中按 ≤ 该值的有界观测处理"）。

这样既**不硬造 floor**、也不**丢弃强证据**，且把"是否删失"变成一个**可审计的显式决定**而不是隐含假设。

## 6｜46 个缺失重复的精确账目

| 项 | AMP 781 | AZT 36 |
|---|---|---|
| 组数 | 55,294 | 55,294 |
| 三重复齐全（`n_observed = 3`） | **55,248** | **55,232** |
| 仅两重复（`n_observed = 2`） | **46** | **62** |
| NaN 单元格总数 | **46** | 62 |

- **46 个 NaN 分布在 46 个不同基因型上，每个恰好缺 1 个重复**（`{1: 46}`）。
- 按 AMENDMENT-009 §3.2：这些是 **`missing replicate`**，**不是** censored、**不是** floor → `n_expected=3, n_observed=2, n_missing=1`，**不得填补**。
- 组内代表值与不确定度由**剩余 2 个有效重复**导出；**不得虚构 SEM**。

示例受影响基因型（前 8 个）：`PKVKST.S..MQD`、`PK.K.TT..C.L.`、`PK.K.T..K..LD`、`PK.KNT..KSM..`、`PKLK.T..KSML.`、`.KVK..TSK....`、`PKLK.TT...MLD`、`PKVK.T...CM.D`。
